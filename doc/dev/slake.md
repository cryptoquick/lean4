# Slake — Systems Lean twin of Lake

**Slake** is the freestanding, residual-free, linear-types build driver that targets the **same external API as Lake**. Lake remains the classic driver. Systems Lean dogfoods **Slake** to demonstrate residual-free product + CompCert PROVABLY + multiplicities 0/1/ω on a real tool.

Canonical Systems Lean narrative: [systems-lean.md](systems-lean.md). Plan SSoT for phased delivery lives in the session plan (`slug: slake`).

| Term | Meaning |
|------|---------|
| **Lake** | Classic Lean package manager / build system (`src/lake/`) |
| **Slake** | Systems Lean twin (`src/slake/`) — same public API, freestanding product cores |
| **API parity** | Same CLI surface + config schema users depend on (phased checklist below) |
| **PRODUCT_GC_FREE** | Freestanding product wire residual-free (embed TCB) |
| **GC_FREE_ELABORATOR** | Host elaborator residual (still measured `0` until H5) — **never forge** |
| **PROVABLY** | Full product TU matrix + residual/sorry/axiom-auto/certs + resolved `ref/CompCert` `ccomp` |

## North star

```
                    same public API
         ┌────────────────┴────────────────┐
         ▼                                 ▼
   lake (classic)                    slake (Systems)
   Init/Std/IO/Lean elab             freestanding + linear 0/1/ω
   GC/RC host OK                     PRODUCT_GC_FREE=1
   no CompCert product claim         MemSafetyCert + PROVABLY ccomp
         │                                 │
         └──────── package configs ────────┘
              (same schema / commands)
```

**Systems Lean uses Slake** as the primary demonstration driver. Lake remains available and is the behavioral reference. Packages should work with either tool as parity grows.

## Hard constraints

1. **Parallel tree** — implement `src/slake/`; **do not** freestanding-ize `src/lake` in place.
2. **Freestanding product** — dual-param / fixed-cap / unboxed C ABI; no Lean RC/GC on product wire.
3. **CompCert PROVABLY** on Slake product TUs (not dogfood-only). Weaker `COMPCERT_DOGFOOD=1` is not the end bar.
4. **Multiplicities** — only grades **0 / 1 / ω**. Dogfood fully on Slake product as built; extend UseCheck when blocked (TDD). No global UseCheck marathon pre-gate.
5. **Config without residual_free elaborator** — freestanding core path uses **`lakefile.toml`** (and/or precompiled artifacts). Full in-process `lakefile.lean` elab is host-side until H5 residual_free host, or classic external elab → decoded artifact.
6. **Dual residual honesty** — product residual-free; host elaborator honest until earned.

## Non-goals

- Deleting Lake.
- Forging residual_free elaborator or PROVABLY without resolved in-tree `ccomp`.
- Marketing “safer than Rust” without greppable gates.
- Calendar estimates — work is sequenced by **phase exit gates** only.

## Architecture

```
 packages (same lakefile.toml / supported lake API)
              │
     ┌────────┴────────┐
     ▼                 ▼
   lake              slake
   classic           freestanding product
     │                 │
     │                 ├─ Systems.* cores (mult 0/1/ω)
     │                 ├─ MemSafetyCert + residual gates
     │                 └─ ccomp PROVABLY on Slake TUs
     │                 │
     └──── spawn lean/cc/git (external processes) ────┘
```

| Layer | Location | Role |
|-------|----------|------|
| Driver / CLI / workspace | `src/slake/` | Same API contract as Lake; may start thin / host-assisted |
| Freestanding cores | `src/Systems/*Lite.lean` (and friends) | Residual-green product math for dep graph, TOML subset, paths, hashes, traces |
| Product matrix / SCORE | `tests/lake/examples/systems/` + `script/systems-*` | Residual, certs, CompCert |
| Classic reference | `src/lake/` | Behavioral source of truth for parity tests |

**Self-host without residual_free elaborator:** TOML (or precompiled) config + external `lean` / `cc` / `git` via process spawn (`Systems.Proc` shipped W62; argv0 + multi-arg + pipe freestanding; classic CLI optional `SLAKE_USE_FS_PROC=1` W68).

## Memory safety bar

| Layer | Mechanism | Gate |
|-------|-----------|------|
| No Lean GC/RC on product wire | Freestanding EmitC residual | `PRODUCT_GC_FREE=1` |
| Affine / linear discipline | Mult 0/1/ω + UseCheck + AffineCheck | freestanding + QTT |
| Explicit free / borrow | `@[fs_borrow]`, dual-param buffers | module design |
| Memory-safety certificates | `MemSafetyCert` | CertsVerify |
| No UB at C (accepted TUs) | CompCert `ccomp` | **`PROVABLY_COMPCERT_COMPLIANT=1`** |

Honest claim shape: structural ownership (linear/affine) + residual-free C + CompCert on accepted TUs. Not claimed: full concurrent memory model, full Rust lifetime polymorphism, elaborator residual_free until H5.

## Multiplicity dogfood policy

| Rule | Detail |
|------|--------|
| Grades | Only **0 / 1 / ω** (R1 done) |
| Global UseCheck residual | **Not** a pre-gate for Slake |
| Slake product code | **Must** live under freestanding + UseCheck/AffineCheck |
| On UseCheck fail | Rewrite dual-param/affine **or** extend UseCheck + regression |
| Lake tree | Unchanged classic Lean |
