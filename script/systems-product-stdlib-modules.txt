# Systems Lean PRODUCT_STDLIB_MODULES — closed freestanding product stdlib set.
#
# This is the authoritative list of Systems product modules that must:
#   1. Exist as src/Systems/<path>.lean
#   2. Build under compiler.freestanding (Lake freestanding := true)
#   3. Be residual-free (nm + IR greps via systems-residual-policy.sh)
#   4. Be cert-sealed + ccomp'd on the product TU matrix
#
# Format (rg-friendly):
#   - One module path per line, relative to Systems/, no .lean/.c suffix
#   - Nested modules use / (e.g. Parallelism/Simd → Systems.Parallelism.Simd)
#   - Lines starting with # and blank lines are ignored
#
# Extract (consumer export surface) is NOT listed here; it is always required
# separately as ir/Extract.c.
#
# Gate: ./script/systems-product-stdlib-check.sh
#   greppable success: PRODUCT_STDLIB_MODULES_OK=1
# Validate: GATE product_stdlib=PASS in systems-validate.sh
#
# Grow this list only when a module passes freestanding build + residual + certs.
# Do NOT list classic Init/Std modules until they are ported under Systems/.
